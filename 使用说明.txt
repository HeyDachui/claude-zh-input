Claude 中文输入法 1.4.4 小范围试用版

这是独立的本地输入工具：普通中文、整句中译英、中英混输、指令库和三套皮肤。无需账号，翻译在本机 CPU 运行，不按次数收费。

一、安装与首次使用
1. 适用于 Windows 10/11 x64。本包只有 x64 输入组件；32 位应用、32 位 Windows 和 ARM64 不在支持范围。已在当前 Windows 11 环境做成品检查，干净 Windows 10 仍待试用。
2. 本版提供程序包与独立模型包。首次使用时，将两包完整解压到同一父目录，进入程序目录，双击“组合模型包.cmd”；校验和组合成功后再安装。模型包以后可复用，程序更新无需重复下载相同模型。程序包本身不能提供自由句离线翻译。保留全部文件。双击“安装输入法.cmd”，按 Windows 提示完成管理员确认。包内带离线运行库与模型，无需另装 Python、开发工具或下载模型。
3. 安装完成后打开设置，按 Win+Space，选择“Claude 中文输入法”。初次使用为普通中文，不改动系统默认输入法。日后可在开始菜单找到同名设置入口。
4. 设置页顶部显示后台版本和已连接输入组件版本。本版后台为1.4.4，输入组件沿用1.4.0；版本不同是预期配置。升级后请保存工作，自行重开需要输入的应用，使其载入新组件。只重启输入法助手，不能替换工作应用内已加载的旧组件。未连接时显示“输入组件未连接”，不等于安装失败。
5. 本试用包的自有程序尚未数字签名。Windows 可能显示未知发布者或进行安全检查；只使用来源可信、完整且校验一致的包，不要关闭安全软件。若被系统拦截，请记录提示并联系提供安装包的人。

二、像普通输入法一样输入
普通中文：全拼或首字母输入；空格/数字选词，↑↓移动候选，PageUp/PageDown翻页。单按 Shift 切换拼音和字母直输。
拼音状态可直接输入大写开头的 OpenAI，空格原样确认，再继续拼音。全小写英文、驼峰变量或整段英文，请先按 Shift 切到字母直输，再按 Shift 切回。连续小写字母可能同时是拼音或英文，程序不会强行猜测。
退格、Delete、左右、Home/End可编辑当前组合。复制、粘贴及其他 Ctrl/Alt/Win 快捷键交由原应用处理。
选择此输入法会按需唤醒助手。主动关闭助手后不会立刻重开；切到其他输入法再切回来即可唤醒。若启动或通信超过约2秒仍无响应，已显示文字会留在原框，新键交回应用，可能出现原始拼音字母。切换输入法恢复后，请核对这段文字。
后台异常、取消翻译、失焦或睡眠通知会终止过期事务，保留已显示原文。这里的恢复能力已做受控测试；真实睡眠、长时间使用及不同宿主仍需小范围试用确认。

三、整句英文与找回原文
点击状态栏“整句英文”，或按 Ctrl+Shift+M 切换。先用拼音选出中文，句号、问号、叹号或回车结束后开始离线翻译。此输入法填入文本，不自动替你发送消息或执行命令。
正常翻译会自动输出英文，不再每句弹出“核对英文”的提醒，也不因句中出现“不要”“确认”“先后顺序”或数字而留成中文。1.2.0的旧拦截设置不会在升级或恢复设置后重新生效。
需要找回中文时，点击状态栏“原文”或设置中的“最近翻译”，选择“复制原文”；也可复制英文。回到需要的输入框粘贴即可。这个入口按需使用，不是每句话的审核步骤。软件不会自动回写另一个窗口；列表也不记录原应用是否已接收或发送。
原文列表仅在本次后台运行的内存中保留最近5条，10分钟后从列表过期，也可手动清空；不写入日志、反馈或设置备份。超过16000字符的原文/译文不进入列表，输入框保留原文并提示在原框分句。翻译引擎本身一次最多处理5000字符，并有进程内缓存，关闭助手后释放；软件没有正文历史文件。
翻译过程中再按回车，会继续等待同一次翻译，不会提交尚未译完的中文。你可以直接输入下一句；已结束的句子依次翻译，完成后在原框按顺序输出英文，后面正在输入的内容继续保留。全部英文写入完成后，再按回车交由应用处理。
按 Esc 保留当前尚未提交的原文。回删或移动到待翻译的前句进行编辑时，相关待处理结果失效，保留文字供编辑。切到别的输入框、移动原框内的光标或由应用修改组合文字后，旧译文不会覆盖新的位置或内容。最多同时排队16句，超过时保留原文并给出分段重试提示。
1.3.0已更换本地整句翻译模型，重点修正否定、确认条件、动作顺序和编程术语。程序会保护代码与数值，并在发现遗漏禁止条件或字面内容时自动重试一次；这些处理在后台完成，不要求使用者审核英文。
完整命中内置、导入语包或个人短语时，直接使用对应英文。尚未选词的拼音、已选中文仍属于已知短语开头时，不为它们启动翻译模型；已选中文超出词库及严格句型前缀后，后台提前准备模型。自由新句仍可离线翻译，冷启动时需要等待模型准备。普通中文模式不为输入加载模型。取消一句时停止这次计算，保留已加载模型；异常进程或取消后约2秒仍无响应时才重新启动翻译进程。
翻译引擎连续闲置5分钟后自动释放，下次使用重新准备。单句轮到处理后通常最多等待约30秒，取消故障清理可额外等待约2秒；排队等待另计。实际转换失败、上下文容量不足或超时会保留中文并显示具体恢复提示。你可以继续输入，也可以在“最近翻译”取回原文。
模型约3.1GB，在CPU上保留4个译文生成线程，句子读取与预热按可用物理核估算1至8个线程；Windows负责实际调度，不强制绑定性能核，不需要显卡或云端账号。请为完整解压、安装和升级临时备份预留至少16GB空闲磁盘；建议使用16GB及以上内存的较新x64电脑。速度与内存用量的本机实测、未覆盖设备和翻译边界见“验证范围.txt”。

四、常用语包、代码、路径与指令
设置 → 常用语可按中英文查找193条内置表达，并导入自己的中英JSON语包；成功后立即生效。同一中文的个人译法优先，语包与内置或其他包出现不同译文时会拒绝导入。同一包ID用于更新，移除和更新保留旧包备份。独立语包和制作示例见 phrase-packs 目录；本版已内置其中143条日常沟通表达，无需重复导入。语包仅覆盖完整句，未命中的新句仍走本地模型。
严格句型可直接翻译带反引号的检查、保留、修改、禁止修改、替换、重命名，以及数值赋值、重试次数、超时时间等完整指令。例如“检查 `src/payments.cs`”“把变量 `delta` 设置为 -0.004000”。反引号内文字逐字保留，数字保留正负号和精度。个人/导入/内置完整短语优先；附加条件、执行人或未支持的说法会交回模型，不用近似句替换。输入数值参数时，小数点保留在句中，请按回车结束该句。
代码、变量、路径建议用反引号包住，例如 `src/登录.ts`、`timeoutMs`、`if (count != 0) return false;`。URL、文件路径、大写标识符及已有英文片段会按规则保护；纯英文/代码直通保留大小写和空格。
整句英文模式输入 ;; 或按 Ctrl+; 打开指令库；选择后填入当前输入位置，不执行命令、不发送 Enter。设置中“查看指令”可浏览，直接填入请从原应用的输入位置打开指令库。
“换皮肤”保留纸笺、夜航、云朵三套外观。字体随包提供，其他机器不必预装同名字体。

五、升级、失败恢复和卸载
升级：结束当前未提交的组合，保留旧安装包；完整解压新程序包，先与配套模型包组合，再运行“安装输入法.cmd”。组合工具也支持显式指定旧完整离线包来复用已校验模型，参数见程序包“组合模型包说明.txt”；不要从正在运行的安装目录手工挪动文件。安装器只重启本产品后台，不关闭编辑器、浏览器等工作应用。个人数据保留，旧的原生组件保留在版本目录，避免强行卸载已被应用加载的 DLL。
从1.1.x升级使用同一输入法标识，列表名由“Claude 中文输入法（Rime 测试）”统一为“Claude 中文输入法”。更早期的托管实验版不在本次升级验证内；系统列表中的历史重复项不会被批量删除。
从1.2.x或1.3.x升级时，安装器重启本产品后台；请随后自行重开需要输入的应用。新版设置顶部后台显示1.4.4、输入组件显示1.4.0，为预期组合。个人模式、词库及其他输入法保留。应用自带完整.NET运行时，所需VC运行库随包提供。不要把新worker或DLL单独复制进旧安装目录。
升级失败：安装器尝试恢复旧程序和登记。若回滚也失败，会明确报出保留的旧版本备份目录；不要删除它。可重新运行原安装包修复，并把安装日志提供给包提供者。安装日志在 %LOCALAPPDATA%\ClaudeZhInput\setup-logs，可能含本机路径，发送前请自行检查。
若要回到旧版本：先退出当前未完成输入，再运行保留的旧完整安装包；不要单独复制 DLL 或 worker.exe。旧版本不支持的新设置可保留在数据目录，但旧版忽略它们。回退后的真实输入仍须在重开的应用中确认。
卸载：从 Windows“已安装的应用”或开始菜单选择卸载，也可运行完整包中的“卸载输入法.cmd”。保留系统其他语言和输入法，不卸载共享运行库，默认保留个人数据。
若 DLL 被应用占用，卸载会保留本产品标记和再次清理入口。保存工作、自行关闭相关应用后，再运行同一卸载入口即可清理；不需要结束所有系统文本服务。

六、个人数据与问题反馈
设置 → 维护与帮助提供数据目录、设置/短语备份、恢复和反馈入口。
“备份设置与短语”包含模式、皮肤、状态栏位置、翻译选项、记录开关及个人短语，含个人内容，请自行保管；不含日志、原文对照、导入语包和 Rime 学习词频。语包请在“常用语”单独导出。恢复前会把原文件逐字节保存在数据目录的“导入前备份-日期-编号”文件夹。可从该文件夹找回导入前的数据。恢复后完成当前输入，关闭助手再切走、切回，个人短语和记录设置随新后台加载。
完整数据目录：%LOCALAPPDATA%\ClaudeZhInput。要迁移学习词频，请先完成输入、切换到系统输入法、关闭助手，再复制整个数据目录；在另一台机器安装同版软件并关闭助手后放回同一位置。不要在后台写词库时复制数据库文件。
要彻底清除个人数据：先卸载并完成占用文件清理，再在资源管理器中打开 %LOCALAPPDATA%，删除其中的 ClaudeZhInput 文件夹。此操作不可恢复，先保留需要的备份；不要删除 Programs 下其他应用。
本地故障记录默认关闭，已有用户的记录开关会保留。可在设置中开关；只记录事件类型、计数、耗时、进程/会话标识等元数据，上限约20 MiB，不记录输入正文、按键值、候选词、窗口标题。关闭助手后可在数据目录删除 behavior-log 清理旧记录。
“生成反馈文件”只写版本、Windows版本、架构及空白问题模板，不自动附加词库、原文或日志。请填写应用版本、发生时间、操作步骤、期望/实际结果和切换后能否恢复，再自行发给提供安装包的人。没有自动上传或内置公共反馈服务器。

七、试用边界
源码检查、保护成品测试、真实用户试用分别见“验证范围.txt”。本版内置193条常用语，增加常用语查找与独立语包导入、导出、更新、移除。完整句命中直接出英文，保留否定、条件和范围，不以相似句替换。本版增加严格句型和程序/模型分包，保留原模型、生成规则、输入组件、协作取消和连续输入队列。两个专用小模型未通过语义检查，未采用；现用模型体积没有缩小。真实工作应用及笔记本体验仍需小范围试用反馈；不会把英语审核交给使用者。
首次试用建议用无敏感内容的临时文档，检查连续输入、快速选词后退格、在两个输入框切换、翻译中取消、关闭助手后切回、睡眠恢复、升级与卸载。若文字、光标或翻译不符预期，先切回系统输入法并保留故障步骤。
自有代码经过编译和混淆，提高提取与逆向成本；本地软件不能保证绝对防逆向。安装维护脚本保持可读，第三方模型、词库、字体和运行库按各自原始许可证分发，许可见 licenses 目录。
