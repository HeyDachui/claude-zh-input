# 安装、启动与卸载

适用 Windows 10/11 x64，不支持 32 位或 ARM64 原生安装。完整解压分享包后，双击根目录“安装输入法.cmd”。安装使用系统 Windows PowerShell 5.1，在注册输入法时请求管理员确认；输入助手按当前用户运行。无需安装 Python 或开发工具。

程序安装到 `%LOCALAPPDATA%\Programs\ClaudeZhInput`，个人词库、模式、皮肤和位置在 `%LOCALAPPDATA%\ClaudeZhInput`。安装包不包含发布者的个人数据。升级保留已有设置；新用户默认普通中文，不改变系统默认输入法。

按 Win+Space 选择“Claude 中文输入法”。配置身份继续为 `0804:{B763D5F3-0F9E-47D2-8CD8-7CCBFA6C3A41}{56E8B5B8-99E6-4C0B-AF16-33C5805FC3D2}`；从 1.1.x 升级不新建另一条 TIP。设置页同时显示后台及已连接输入组件版本。1.4.0需要重开原来的工作应用，使其载入连续输入组件。正常翻译直接输出英文；原文入口按需找回，不要求逐句核对。

## 日常使用

普通中文按拼音选词。单按 Shift 切换字母直输；拼音状态直接输入 OpenAI 等大写开头片段，空格原样确认。Ctrl+Shift+M 切换普通中文和整句英文；整句英文模式在句号、问号、感叹号或回车处翻译提交，Esc 或翻译失败保留中文。

双击“打开设置.cmd”打开设置及纸笺、夜航、云朵皮肤。助手随用户登录启动；关闭助手后，切到其他输入法再切回来可按需唤醒。后台已存在时复用同一进程。冷启动阶段短暂保留输入等待服务就绪；约 2 秒仍无响应时保留已有文字，并让新按键交回应用处理。断线后不重放旧按键。日常翻译使用本地 CPU，不需要 API 密钥或显卡。

## 升级和卸载

原生 DLL 按内容哈希放到 `native\versions\v-<hash>`。升级不覆盖正被其他应用加载的 DLL；请自行重开使用中的编辑器或终端，让它载入新版。安装失败时恢复上一版本的文件及注册。

双击“卸载输入法.cmd”注销本版输入法并移除自身启动项。个人词库与设置、系统共享运行库保留。若 DLL 仍被工作应用占用，其余卸载先完成；关闭相应应用后再次卸载即可清理。

## 命令与排障

```powershell
.\setup\install.ps1
.\setup\start.ps1 -Settings
.\setup\start.ps1 -Stop
.\setup\uninstall.ps1
```

若直接从管理员 PowerShell 安装，安装器不会在高权限进程中启动助手。安装后从普通 PowerShell 执行 `setup\start.ps1`。安装日志在 `%LOCALAPPDATA%\ClaudeZhInput\install-log`，可按失败步骤排查。

这些命令的 `-Simulate` 只检查路径、清单和分支，不注册输入法或改动用户设置。确有需要时，安装和卸载的 `-RestartTextServices` 可重启当前会话文本服务；默认不启用。

应用自带完整.NET桌面运行时，不需要额外安装全局.NET，也不再附带重复安装器。包内保留已校验微软签名及摘要的VC++ x64 Runtime，需要时安装；卸载本产品不删除系统共享运行库。版本、下载来源及摘要在 `prerequisites` 中的JSON文件。

自有程序尚未数字签名。核对发布来源及 ZIP 的 SHA-256；不要关闭安全软件。公开测试范围与尚未覆盖的项目见根目录“验证范围.txt”。
